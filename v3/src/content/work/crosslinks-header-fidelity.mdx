The Vault CRM to PromoMats integration packages custom source files into CrossLinks so CLM presentations and rich media transfer with full fidelity, removing what had been a manual file hand-off. When that pipeline degraded, the symptoms were bad but vague: syncs that should have finished quickly were running past four hours, and a backlog of more than 80,000 messages had built up behind it.

Nothing was erroring. The failure was silent, and that silence was itself what made it hard to localize — a crash tells you where to look, and this didn't. The root cause turned out to be Tomcat silently dropping non-ASCII HTTP headers, which corrupted the fidelity of source files with international filenames.

Fixing the header handling drained the backlog and eliminated the four-plus-hour sync times. The notable part of this one isn't the fix — it's that the bug never announced itself. No crash, no exception, nothing in the logs pointing at a cause; the pipeline just kept getting slower until the fix landed.
