Vault File Manager is a native Windows C#/.NET client, and I was the sole engineer on it. There was no one else to route an issue to and no team to share ownership with — whatever came up on that codebase was mine to resolve.

One of the P2 production issues I resolved was upload resiliency at scale — sessions of 39,000 or more files. Fixing it meant making the upload path resilient at that scale.

Separately, I remediated a phantom DLL-hijacking vulnerability across more than 30 libraries in the codebase.

Being the only engineer on Vault File Manager means every decision on scope and priority for issues like these is mine to make, with no one else to weigh in before they ship.
