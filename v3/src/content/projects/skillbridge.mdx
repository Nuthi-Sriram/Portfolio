SkillBridge is an AI-powered career coach. It analyzes a resume against a target job description to identify skill gaps, generate course recommendations to close them, and provide interview preparation support.

The backend is built with FastAPI and MongoDB, the frontend with Next.js, and the analysis is powered by Gemini.
