Gossip Scope is an interactive visualization simulating the Gossip distributed protocol. It renders real-time graphical propagation across a simulated network of nodes, includes node-failure testing to show how propagation behaves when nodes drop out, and exposes interactive parameter controls for adjusting the simulation.

Built with React and D3.js for the visualization layer, in JavaScript.
