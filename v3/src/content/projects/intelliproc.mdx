IntelliProc is a dual-camera proctoring system for remote exams, using mobile and webcam integration to monitor test-takers. Built with Node.js and React.

The work was published as a book chapter, "Intelligent Proctoring System," in *ICT with Intelligent Applications* (Smart Innovation, Systems and Technologies, pp. 247–258), Springer Nature Singapore, 2022.
