This is a personal project, built outside of any professional engagement. It is a complete implementation of the Raft consensus algorithm in C++, covering fault-tolerant leader election and log replication to keep distributed state consistent across nodes.

Sriram's professional engineering work is in Java and C#/.NET, not C++ — this project does not reflect production experience with the language. It was written independently, on his own time, to work through Raft's mechanics directly.
