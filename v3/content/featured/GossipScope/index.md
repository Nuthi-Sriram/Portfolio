An interactive visualization tool that simulates the Gossip distributed protocol, featuring real-time graphical propagation, node failure testing, and interactive parameter controls.

Gossip protocols spread state across a cluster through randomized peer-to-peer exchange rather than centralized coordination. The tool renders that propagation as it happens, and lets you kill nodes mid-run to watch the cluster route around them and still converge.
