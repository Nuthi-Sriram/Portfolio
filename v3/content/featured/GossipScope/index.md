An interactive visualization tool that simulates the Gossip distributed protocol, featuring real-time graphical propagation, node failure testing, and interactive parameter controls.

Gossip protocols spread state across a cluster through randomized peer-to-peer exchange rather than centralized coordination. Watching propagation unfold — and watching it route around deliberately failed nodes — makes the protocol's convergence behaviour visible in a way a specification does not.
